# Sandy-Blu Guest House — WebDevPro Ultra Max 5 Rebrand

A Vercel-ready React + Vite + TypeScript rebrand based on the supplied WebDevPro Ultra Max 5 master template and the Sandy-Blu Guest House reference designs.

## Pages
- Home
- Accommodation
- Explore & Contact

## Features
- Responsive coastal navy/gold design
- Room showcase
- Facilities section
- Availability form that sends booking enquiry to WhatsApp
- Floating WhatsApp button
- Mobile footer navigation
- PWA manifest/service worker files
- Vercel SPA routing

## Deploy
1. Upload all files to a GitHub repository.
2. Import the repository into Vercel.
3. Framework: Vite
4. Build command: `npm run build`
5. Output directory: `dist`

Designed by WebDevPro.
